# noun-learning
CHS noun learning repository
noun-learning
Stimuli for the noun-learning study (between-subjects: orthographic support vs. no orthographic support) on Children Helping Science. Base directory used by the protocol generator:
https://raw.githubusercontent.com/Grace-Clark/noun-learning/main/
File names are case-sensitive. Do not use Git LFS for videos (raw links would return a pointer file instead of the video).
